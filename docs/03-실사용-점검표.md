# 실사용 점검표 — 학교 PC 에 처음 설치한 뒤

담당자가 차례대로 체크합니다. 연습은 **연습용 앱**이 아니라도 괜찮지만, 마지막 실제 발급 전에는 시험 발급을 **취소**해 두세요
(취소한 번호는 다시 쓸 수 없으니 시험에는 NEIS 번호가 아닌 `시험-001` 같은 번호를 씁니다).

## 설치·확인
- [ ] 설치할 때 관리자 권한을 묻지 않았다
- [ ] 시작 메뉴에 **방과후 강사 경력증명서** 가 있다
- [ ] 왼쪽 아래에 **연습용 표시가 없다** (실제용 앱이다) · 버전 `v0.1.0`
- [ ] 설정 → 데이터 관리의 자료 파일 위치가 `%APPDATA%\kr.school.careercert\` 이다

## 학교 정보
- [ ] 학교 기본정보 7칸을 입력하고 저장했다
- [ ] 대시보드의 "학교 기본정보" 칸에 학교명·발급자·담당자가 맞게 보인다

## 엑셀 가져오기
- [ ] 기존 강사명단 엑셀을 **[반영 미리보기]** 까지 하고 건수가 맞다
- [ ] "검토 필요"(마감날짜 빈칸) 줄을 하나씩 확인했다
- [ ] 같은 이름 강사를 바르게 연결/새로 등록했다
- [ ] 가져온 뒤 강사관리에서 강사 수·경력이 엑셀과 맞다

## 증명서
- [ ] 시험 강사로 **[실제 출력 미리보기]** 를 보고 양식이 맞다(제목·경력 표·학교장·담당)
- [ ] 시험 발급(번호 `시험-001`) → **실제 프린터로 1부 출력**
  - [ ] A4 한 장 안에 잘림 없음
  - [ ] 한글 글꼴이 깨지지 않음
  - [ ] 표 테두리가 이어짐
  - [ ] 경력 표·학교장·담당 정보가 맞음
  - [ ] 주민등록번호 전체 표시 또는 뒷자리 가림이 고른 대로 나옴
  - [ ] 경력이 많은 강사로 2쪽 이상이 되면 쪽 머리글·쪽 번호가 나옴
- [ ] **[PDF 저장]** 이 되고 PDF 를 열면 종이와 같다
- [ ] (로고를 쓴다면) 설정 → 학교 로고 등록 → 시험 발급 → 종이에 **연한 흑백 로고**가 경력 표 뒤에 나오고 글자가 잘 읽힌다
- [ ] 시험 발급을 **취소**했다(발급이력에서 '취소' 확인)
- [ ] (필요하면) 잘못 확정한 시험 발급을 **오발급 폐기** → 발급이력에서 사라지고 같은 번호로 다시 발급된다

## 복구·백업
- [ ] 복구 비밀번호를 설정했다 (10자 이상 긴 문장)
- [ ] 복구 비밀번호를 **종이에 적어 안전한 곳**에 보관했다 (PC 안에 파일로 두지 않음)
- [ ] **[백업 내보내기]** 로 이동용 백업을 만들었다
- [ ] 백업 파일을 **PC 밖 안전한 곳**(학교 보안 USB 등)에 옮겨 두었다
- [ ] 대시보드의 백업 안내가 사라졌다

## 업데이트
- [ ] 새 버전이 나오면 왼쪽 아래 알림 → **[업데이트]** 로 설치하고, 다시 켜진 뒤 버전이 바뀌고 자료가 그대로인지 본다
