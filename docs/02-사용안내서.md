# 방과후 강사 경력증명서 — 사용 안내서 (v0.1.0)

방과후학교 개인위탁 외부강사의 경력을 관리하고 **경력증명서(활동 확인서)** 를 발급하는 Windows 프로그램입니다.
자료는 이 컴퓨터에만 저장됩니다. 인터넷은 새 버전 확인에만 씁니다.

> **꼭 알아 두세요**
> - 주민등록번호·주소는 **강사 원장에 저장하지 않습니다.** 증명서를 발급할 때만 입력하고, 발급 기록에 **암호화**해 저장합니다.
> - **복구 비밀번호**를 잃어버리면 다른 PC·다른 Windows 계정에서는 발급 기록의 주민등록번호·주소를 되살릴 수 없습니다.
> - 기존 이동용 백업은 **그 백업을 만들 때의 복구 비밀번호**가 있어야 열립니다.
> - **취소한 발급번호는 다시 쓸 수 없습니다.**
> - **재출력**(같은 증명서를 다시 인쇄)과 **이 내용으로 새 증명서 작성**(새 발급번호로 새 증명서)은 다른 기능입니다.

---

## 1. 설치

1. 배포 페이지에서 `careercert_0.1.0_x64-setup.exe` 를 내려받아 실행합니다. **관리자 권한이 필요 없습니다**(현재 사용자에게만 설치).
2. Windows 가 "PC를 보호했습니다" 창을 띄우면 **추가 정보 → 실행** 을 누릅니다(코드 서명 인증서가 없는 프로그램이라 나오는 안내입니다).
3. 설치가 끝나면 시작 메뉴에 **방과후 강사 경력증명서** 가 생깁니다.

| 무엇 | 어디 |
|---|---|
| 프로그램 | `%LOCALAPPDATA%\방과후 강사 경력증명서\` |
| 자료(DB) | `%APPDATA%\kr.school.careercert\careercert.db` |
| 앱 안 자동 백업 | `%APPDATA%\kr.school.careercert\backups\` |

- 프로그램을 **지우거나 다시 설치해도 자료는 남습니다.** (설정 → 데이터 관리에서 위치를 볼 수 있습니다.)
- 새 버전이 나오면 프로그램 왼쪽 아래에 알림이 뜹니다. **[업데이트]** 를 누르면 내려받아 설치하고 다시 켜집니다.
  자료 구조가 바뀌는 판은 첫 실행 때 바뀌기 직전 자료를 자동으로 백업합니다.

## 2. 첫 실행

- 왼쪽 아래에 **연습용** 표시가 있으면 연습용 프로그램입니다(실제 자료와 따로 저장). 실제 업무는 연습용 표시가 **없는** 프로그램으로 합니다.
- 대시보드에 "학교 기본정보가 아직 다 채워지지 않았습니다" 가 보이면 다음 단계로 갑니다.

## 3. 학교 기본정보 설정 (설정)

학교명 · 발급자 표기(예: ○○초등학교장) · 담당부서 · 담당자 · 전화번호 · 문서 제목 · 기본 용도를 입력하고 **저장** 합니다.
증명서 아래쪽 학교장·담당 칸에 들어갑니다. 바꾸면 **앞으로 발급하는 증명서**에만 반영되고, 이미 발급한 증명서는 바뀌지 않습니다.

## 4. 기존 Excel 강사명단 가져오기 (강사관리 → 엑셀 가져오기)

1. **[엑셀 파일 고르기]** — `.xlsx`·`.xlsm` 을 고릅니다. 파일을 **읽기만** 하고 매크로(VBA)는 실행하지 않습니다.
2. 분석 결과를 확인합니다 — 시트(기본 `강사명단`), 머리글 줄, 읽은 열(성명·프로그램명·직위·시작날짜·마감날짜·지도사항), 줄별 판정.
   - **정상** / **경고**(오늘 이후 날짜 등 — 가져옵니다) / **검토 필요**(마감날짜가 비어 있음) / **오류**(없는 날짜, 시작이 마감보다 늦음, 빈 칸) / **파일 안 중복**
   - 마감날짜에 `현재`·`재직중`·`재직`·`근무중` 이 있으면 **재직중**으로 가져옵니다.
   - 마감날짜가 **비어 있으면** 재직중이라고 단정하지 않습니다. 그 줄의 **[재직중으로]** 를 체크해야만 가져옵니다.
3. **강사 연결** — 같은 이름의 강사가 이미 있으면 **자동으로 합치지 않습니다.** 이름마다 고릅니다.
   - 기존 강사와 연결 / 새 강사로 등록(같은 이름이 있으면 **구분 메모 필수** — 예: 1985년생) / 가져오지 않음
4. **[반영 미리보기]** 로 실제로 넣을 건수를 확인한 뒤 **[가져오기]**. 가져오기 직전 자료를 앱 안에 자동 백업합니다(`before_import`).
5. 과거 엑셀의 **발급번호·발급 기록은 가져오지 않습니다**(강사와 경력만).

**알려진 제한**
- 한 엑셀 파일 안에 **같은 이름의 다른 사람**이 있으면 구별하지 못하고 한 사람으로 묶습니다. 엑셀에서 이름을 구분해(예: 김가온A) 두거나 나눠서 가져오세요.
- 열은 **머리글 이름으로 자동 대응**합니다(성명/이름, 시작날짜/시작일 …). 머리글이 다르면 엑셀에서 머리글을 고쳐 주세요.
- 엑셀 날짜 숫자는 1900 체계로 읽습니다. 옛 Mac 엑셀의 **1904 체계**는 날짜 형식이 입혀진 칸이 있을 때만 알아냅니다.

## 5. 강사·경력 관리 (강사관리)

- 강사 등록·수정·보관, 경력 추가·수정·**종료 처리**·보관. 같은 이름의 강사는 **구분 메모**로 가립니다.
- 학년도 말에는 **[재직중 경력 일괄 종료]** — 고르고 → 미리보기 → 승인. 프로그램이 저절로 종료하지 않습니다.

## 6. 증명서 작성 (증명서 발급)

1. 강사 선택 → 2. 넣을 경력 선택(기본 전부) → 3. 발급 정보(주민등록번호·주소·발급번호·용도·발급일·뒷자리 가림) → **[증명서 내용 확인]**
- 기간은 **발급일 기준**으로 계산합니다(재직중이면 "~ 현재").
- **[실제 출력 미리보기]** 로 종이 모양을 봅니다("발급 전 미리보기" 표시가 찍혀 있어 그대로는 쓸 수 없습니다).
- 주민등록번호·주소는 이 화면에만 있다가 화면을 떠나면 지워집니다.

## 7. NEIS 민원 등록 후 발급번호 입력

NEIS 에서 민원을 등록하고 받은 번호를 **그대로** 발급번호 칸에 적습니다. 프로그램은 앞뒤 공백만 정리하고 바꾸지 않습니다.
이미 쓴 번호(취소된 것 포함, 공백만 다른 것 포함)는 받지 않습니다.

## 8. 발급 확정

**[발급 확정]** 창에서 발급번호·성명·발급일·용도·경력 건수·주민번호 표시·학교장 표기를 확인합니다.
경고(발급일이 1년 넘게 지남, 종료일이 발급일 뒤, 주민번호 생년월일 이상)는 하나씩 체크해야 확정됩니다.
확정하면 그 순간의 내용이 **고칠 수 없는 발급 기록**이 되고 주민등록번호·주소는 암호화되어 저장됩니다.
나중에 강사·경력·학교 설정을 바꿔도 **이미 발급한 증명서는 그대로**입니다.

## 9. 인쇄 / PDF

- **[인쇄]** — 프로그램 안에서 프린터와 매수(1~5부)를 고르고 "○○ 프린터로 1부 인쇄합니다" 를 확인한 뒤 보냅니다.
  '성공'은 프린터 대기열로 보냈다는 뜻입니다(종이가 실제로 나왔는지는 프린터에서 확인).
- **[PDF 저장]** — 위치를 고릅니다. 파일 이름에는 주민번호·주소가 들어가지 않습니다. 저장한 PDF 는 프로그램이 지우지 않습니다(안전하게 관리해 주세요).

## 10. 발급이력 · 재출력 · 취소 · 새 증명서 작성 (발급이력)

- 성명·발급번호(일부)·발급일 기간·상태(발급/취소)로 찾고, 줄을 누르면 발급 당시 내용을 봅니다. 주민번호는 가린 값만 보입니다.
- **재출력**: 같은 발급 기록을 그대로 다시 인쇄·PDF 저장합니다. 발급번호·발급일·내용이 같고 새 기록을 만들지 않습니다. 출력할 때마다 이력이 남습니다.
- **발급 취소**: 사유를 적으면 취소됩니다. 취소한 건은 정식 출력할 수 없고 **그 발급번호는 다시 쓸 수 없습니다.**
- **이 내용으로 새 증명서 작성**: 그 기록을 참고해 **새 증명서**를 씁니다(재출력이 아닙니다). 강사·용도·주민번호 표시 방식·경력 선택만 가져오고
  경력 기간은 **지금 원장과 오늘 날짜로 다시 계산**합니다. 주민등록번호·주소·발급번호는 새로 입력하고, NEIS 에서 받은 **새 번호**로 확정합니다.

## 11. 복구 비밀번호 설정 (설정 → 데이터 관리)

- **복구 비밀번호** 는 PC 고장·교체나 Windows 계정 변경 때 발급 기록의 주민등록번호·주소를 되살리고, 이동용 백업을 만들고 여는 데 씁니다.
  같은 PC 에서 평소 발급·출력할 때는 묻지 않습니다.
- 10자 이상(문자 조합 강제 없음, 앞뒤 공백도 비밀번호). **기억하기 쉬운 긴 문장**을 권합니다.
- **프로그램도 비밀번호를 확인하거나 되찾아 줄 수 없습니다.** 종이에 적어 학교의 안전한 곳에 보관하는 등 잃어버리지 않게 해 주세요.
- **[복구 비밀번호 변경]** — 지금 비밀번호를 알 때. 지금 비밀번호가 맞아야 바뀝니다.
- **[비밀번호를 잊었을 때 (재설정)]** — 지금 비밀번호를 모를 때. **이 PC·이 Windows 계정에서 자료를 열 수 있을 때만** 됩니다.
  재설정해도 **예전에 만든 이동용 백업은 예전 비밀번호로만 열립니다.** 재설정한 뒤에는 새 이동용 백업을 만드세요.
- 발급 기록이 있는데 설정하지 않았으면 대시보드와 설정에 경고가 계속 보입니다.

## 12. 이동용 백업 (설정 → 데이터 관리 → 백업 내보내기)

| | 앱 안 자동 백업 | 이동용 백업 |
|---|---|---|
| 만드는 때 | 하루 한 번, 자료 구조 업데이트·가져오기·복원 직전 (저절로) | 담당자가 **[백업 내보내기]** 를 눌러서 |
| 위치 | 이 PC 의 자료 폴더 `backups` | 담당자가 고른 곳(USB 등) — `*.careercert-backup` |
| 쓰임 | 이 PC 안에서 되돌리기 | **다른 PC 로 옮기기**, PC 고장 대비 보관 |
| 보호 | 주민번호·주소만 암호화 | **파일 전체**를 복구 비밀번호로 암호화 |

- 복구 비밀번호가 있어야 만들 수 있습니다. 파일 이름에는 개인정보를 넣지 않습니다(예: `방과후강사경력관리_백업_20261001.careercert-backup`).
- 만든 파일은 **PC 밖의 안전한 곳**(학교 보안 USB 등)에 보관하세요. 자료가 바뀌었거나 30일이 지나면 대시보드·설정에 안내가 보입니다.

## 13. 다른 PC 에서 복원 (설정 → 데이터 관리 → 백업 복원)

1. 새 PC 에 프로그램을 설치하고 켭니다.
2. **[백업 복원]** → 이동용 백업 파일 선택 → **그 백업을 만들 때의 복구 비밀번호** 입력 → **[확인]**.
3. 프로그램이 백업을 풀어 **모든 발급 기록을 열어 확인**한 뒤 미리보기(강사·경력·발급·취소 건수, 지금 자료와 비교)를 보여 줍니다.
   이때까지 지금 자료는 바뀌지 않습니다.
4. "현재 자료 전체가 선택한 백업의 자료로 교체됩니다" 를 확인하고 **[복원하고 다시 시작]**.
   지금 자료를 먼저 자동 백업(`before_restore`)하고, 프로그램이 다시 켜지면서 교체·재확인합니다. 실패하면 지금 자료로 되돌립니다.
5. 다른 PC·계정의 백업이면 복구 비밀번호로 자료 키를 풀어 **이 PC·이 계정으로 다시 보호**합니다(발급 기록의 암호문은 그대로).

## 14. 주의사항

- **주민등록번호·주소**: 강사 원장에 저장하지 않습니다. 발급 확정 때 암호화해 발급 기록에만 저장합니다. 화면의 발급이력에는 가린 값만 보입니다.
- **복구 비밀번호를 잃어버리면**: 이 PC·이 계정에서는 계속 쓸 수 있고 재설정도 할 수 있지만, 다른 PC·계정에서는 예전 백업의 주민번호·주소를 되살릴 수 없습니다.
- **기존 이동용 백업**은 그 백업을 만들 때의 비밀번호가 있어야 열립니다. 비밀번호를 바꾸거나 재설정해도 예전 백업은 바뀌지 않습니다.
- **발급 취소 번호는 다시 쓸 수 없습니다.** 잘못 발급했으면 취소하고 NEIS 에서 새 번호를 받아 새로 발급합니다.
- **재출력**은 같은 증명서를 다시 찍는 것이고, **새 증명서 작성**은 새 발급번호로 새 기록을 만드는 것입니다.
- 저장한 PDF·인쇄물·이동용 백업 파일은 프로그램 밖에 있으므로 학교의 개인정보 관리 기준에 따라 보관·파기해 주세요.
- Windows 를 다시 설치하거나 PC 를 바꾸기 **전에** 이동용 백업을 만들어 두세요.
