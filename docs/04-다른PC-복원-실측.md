# 다른 PC·Windows 계정 복원 실측 · 실제 프린터 출력 (Phase 9 — 담당자가 직접)

자동 시험과 연습용 앱에서는 "다른 PC" 를 **흉내**(이 PC 가 풀 수 없는 DPAPI 사본)로만 확인했습니다.
아래는 실제 다른 Windows 계정 또는 다른 PC 에서 해 볼 순서입니다. **가상 자료로만** 해 주세요.

## 준비 (PC/계정 A — 지금 쓰는 PC)
1. 설치본 v0.1.0 을 켭니다(연습용 아님).
2. 학교 정보를 가상 값(예: ○○초등학교)으로 넣고, 가상 강사 1명·경력 2건을 만듭니다.
3. 가상 값으로 증명서를 **발급 확정**합니다(번호 예: `실측-001`, 주민번호는 가상 `900101-1000001` (privacy:fake), 주소 `가상시 연습구 1`).
4. 설정 → 데이터 관리 → **복구 비밀번호 설정** → **백업 내보내기** → USB 에 저장.

## 복원 (PC/계정 B — 다른 Windows 계정 또는 다른 PC)
| 단계 | 확인할 것 | 결과 |
|---|---|---|
| 1. 설치본 v0.1.0 새로 설치 | 관리자 권한 없이 설치됨 | ☐ |
| 2. 켜기 | 빈 자료로 열림 · 연습용 표시 없음 | ☐ |
| 3. 설정 → 데이터 관리 → **백업 복원** → USB 의 파일 선택 | 파일·만든 시각·자료 구조 v7 이 보임 | ☐ |
| 4. A 의 복구 비밀번호 입력 → [확인] | 미리보기에 **"다른 PC·계정의 백업입니다"** · 발급 기록 N건 모두 확인 | ☐ |
| 5. 확인 체크 → **[복원하고 다시 시작]** | 프로그램이 닫혔다가 **저절로 다시 켜짐** | ☐ |
| 6. 대시보드 | "이동용 백업(…)에서 복원했습니다 … 발급본 N건을 모두 열어 확인했습니다" | ☐ |
| 7. 발급이력 | `실측-001` 이 보이고 상세가 열림(가린 주민번호) | ☐ |
| 8. 상세 → **PDF 저장** | PDF 에 주민번호·주소가 원래대로 찍힘 | ☐ |
| 9. (선택) 인쇄 | 실제 프린터로 출력됨 | ☐ |

**복원 전에 A 의 키로는 B 에서 열 수 없다는 것** 은 4번에서 판정됩니다("다른 PC·계정"). 4번에서 "같은 PC" 로 나오면 같은 계정에서 한 것이니 다시 확인해 주세요.

## 실제 프린터 출력 (학교 PC)
가상 자료로 발급한 증명서를 실제 프린터로 1부 출력해 확인합니다.

| 확인 | 결과 |
|---|---|
| A4 용지에 맞게 나오고 잘린 곳이 없다 | ☐ |
| 한글 글꼴이 깨지지 않는다 | ☐ |
| 표 테두리가 끊기지 않는다 | ☐ |
| 경력 표(부터·까지·프로그램명·직위·지도사항)가 맞다 | ☐ |
| 경력이 많으면 2쪽으로 나뉘고 쪽마다 머리글·쪽 번호가 있다 | ☐ |
| 학교장(직인)·담당부서·담당자(인)·전화번호가 맞다 | ☐ |
| 주민번호 전체 / 뒷자리 가림이 고른 대로 나온다 | ☐ |

결과(☐ 체크와 이상한 점)를 알려 주시면 최종 보고에 넣습니다.
